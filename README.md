# JOIN THE QUEUE

A frontend-only subscription queue prototype built with React, TypeScript, and Vite.
It uses in-memory demo data and does not connect to a backend, process payments, or
require API keys or secrets. Admin and support views are local previews, not secure
authentication.

## Run locally

**Prerequisite:** Node.js

1. Install dependencies: `npm install`
2. Start the development server: `npm run dev`
3. Create a production build: `npm run build`

All changes made in the demo are held in browser memory and reset when the page is
reloaded.
